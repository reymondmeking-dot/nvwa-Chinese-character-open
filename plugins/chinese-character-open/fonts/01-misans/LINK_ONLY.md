# 01 — MiSans

This repository intentionally contains no MiSans font binary. The MiSans license does not permit redistribution of the font or its copies as an independent font resource.

- Official download and license: https://hyperos.mi.com/font/zh/download/
- Distribution mode: `link-only`

Download it from Xiaomi and follow the current official terms if you want to use it in a product.
