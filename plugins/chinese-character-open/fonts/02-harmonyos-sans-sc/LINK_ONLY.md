# 02 — HarmonyOS Sans SC

This repository intentionally contains no HarmonyOS Sans font binary. Its license permits bundling unmodified copies with non-font software, but this repository is a font collection and therefore does not redistribute the binary.

- Official resource and license page: https://developer.huawei.com/consumer/cn/design/resource-V1/
- Distribution mode: `link-only`

Download it from Huawei and follow the current official terms if you want to bundle it with software.
